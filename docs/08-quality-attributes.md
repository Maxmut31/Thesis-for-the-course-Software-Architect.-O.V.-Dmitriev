# 8. Атрибуты качества

Атрибуты качества описывают нефункциональные характеристики системы,
которые оказывают существенное влияние на архитектурные решения.

При выборе архитектуры системы были выделены три основных атрибута качества:

- масштабируемость
- безопасность
- наблюдаемость

Эти атрибуты напрямую связаны с особенностями разрабатываемой системы.

---

# Масштабируемость

## Описание

Система должна поддерживать большое количество пользователей
по всему миру и обеспечивать стабильную работу во время
резких скачков нагрузки.

Например, во время проведения соревнований или массовых
челленджей количество пользователей, одновременно
использующих систему, может значительно увеличиваться.

## Архитектурные решения

Для обеспечения масштабируемости используются следующие подходы:

- использование микросервисной архитектуры
- горизонтальное масштабирование сервисов
- использование облачной инфраструктуры
- независимое масштабирование отдельных сервисов

Например, сервис соревнований может масштабироваться
отдельно от других сервисов во время проведения
спортивных мероприятий.

---

# Безопасность

## Описание

Система работает с персональными данными пользователей,
включая данные о тренировках, физической активности
и геолокации.

Поэтому защита пользовательских данных является одним
из ключевых требований к системе.

## Архитектурные решения

Для обеспечения безопасности используются следующие меры:

- шифрование пользовательских данных
- контроль доступа к сервисам
- безопасная передача данных
- разграничение доступа между сервисами

Также архитектура должна обеспечивать защиту
от несанкционированного доступа к данным пользователей.

---

# Наблюдаемость

## Описание

Система состоит из нескольких сервисов и может
разворачиваться в распределенной инфраструктуре.

Для поддержки и развития системы необходимо иметь
возможность наблюдать за её состоянием и
быстро выявлять проблемы.

## Архитектурные решения

Для обеспечения наблюдаемости используются следующие подходы:

- централизованное логирование
- мониторинг состояния сервисов
- сбор метрик работы системы
- система оповещений о сбоях

Наблюдаемость позволяет быстрее обнаруживать
и устранять проблемы в работе системы.
